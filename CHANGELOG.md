# Changelog
- 2026-10-18: Initial public version with pictures, navigation, list/grid view.
- 2026-10-18: Served as a full HTML document (standards mode, charset, mobile viewport) plus SEO: description, canonical, Open Graph, JSON-LD, sitemap.xml, noscript text. Research: Google indexes JS-rendered pages but needs these tags and a sitemap to understand them.
- 2026-10-18: Added a social share preview image (og.png) so links shared in chats and social posts show a picture. Research: pages with a 1200x630 image get larger, more clickable previews.
- 2026-10-18: Added a "Not for me" button on every artist (saved in the browser, with Undo and a "show hidden artists again" link). Research: music-discovery users complain about repeats and things they already know, and ask to block or dismiss items.
- 2026-10-18: Find-similar results now have a shareable link (#like=ID) and a "Copy link to these results" button; opening a link shows those results. Research: Bandcamp pages feel like disconnected islands, while Music-Map is praised for simple, passable results.
- 2026-10-18: Added "Order results by: Closest match / Smallest first" on Find similar (remembered in the browser). Research: users ask for a discover-vs-familiar control, and a study found recommendations are least accurate for fans of beyond-mainstream music.
- 2026-10-18: Added "Hide <genre> from All genres" (and a way to show hidden genres again), remembered in the browser. Research: Spotify users say new-release lists are crowded with genres they don't like and ask for a "play less of this genre" control.
- 2026-10-18: Added an "Autoplay next" toggle for previews: when a 30-second preview ends, the next artist in the list starts (off by default, remembered). Research: SoundCloud, YouTube Music and Spotify have all added quick-sampling preview formats because listeners want to skim many artists fast.
- 2026-10-18: Accessibility: added a "Skip to search and results" link (first Tab stop) and kept keyboard focus in the list after hiding an artist. Research: WebAIM and WCAG guidance list skip links and focus management as core keyboard-access requirements.
- 2026-10-18: Added a "Recent" row of your last 8 Find-similar searches (saved in the browser, with Clear). Research: Spotify users say they lose artists they liked when lists refresh and ask for a history to go back to.
- 2026-10-18: Shortlist upgrades: "Copy shortlist link" (opens on any device and merges the artists in, with Undo), plus a Deezer link and Remove button on each entry. Research: users complain favorites don't sync between phone and computer and ask for watch lists to check artists later.
- 2026-10-18: Added a Theme switch (Auto / Light / Dark), remembered in the browser and applied before the page paints. Research: Last.fm users install extensions just to get dark mode, and Spotify users request a light mode, so people want to choose.
- 2026-10-18: Added a Release type filter on Discover (All / Albums / EPs / Singles), remembered in the browser. Research: release-tracking apps like MusicHarbor sell filtering by release type, and singles make up about 75% of the recent releases here, so albums were buried.
- 2026-10-18: Added a "Surprise me: open a random artist" button in the page header (respects fan limit, hidden artists and hidden genres). Research: Spotify users ask for a random-music button that ignores their taste, and Bandcamp's Discoverinator was built to recreate chance finds. Note for later: the controls area is getting crowded and could be tidied.
- 2026-10-18: Added a "My page" tab: a customizable profile (name, tagline, bio, accent color, background, font, corners, links), SoundCloud player embeds for the visitor's own tracks, an "Auto-style from my taste" helper (not an AI), and a share link that opens the page read-only. Saved in the browser only; no sign-in yet. Shared links are sanitized and only soundcloud.com permalinks can be embedded. Also fixed the phone tab row so three tabs fit. Requested by the owner.
- My page v2 (requested by the owner): 12 quick looks, custom colors/gradients/patterns, 11 fonts, layouts, borders, shadows, animations, floating effects, 7 synthesized ambient sounds, click-to-enter screen, YouTube videos and looping banner video, tags, favorite artist, section reorder, side-by-side live preview, visitor view, backup/restore, compressed share links.
- 2026-10-19: Keyboard shortcuts: press / to jump to search and S for a random artist (ignored while typing and on My page). Research: Every Noise at Once fans mourn its fast, keyboard-friendly browsing after it was shut down.
